# Project Atlas — Evaluation Report

## 1. Overview

Project Atlas is a prototype market research report copilot built with FastAPI and Python. It retrieves report excerpts, applies client-level report entitlement rules, identifies selected market-size and CAGR conflicts, and supports a standalone CAGR projection calculator.

## 2. Automated Tests

The current automated test suite contains 9 tests.

- API health endpoint.
- Prompt-injection refusal.
- Unknown-client handling.
- Client C-02 access restriction for paid report R-101.
- Client C-01 access to R-101.
- Client C-02 access to public excerpt R-102.
- CAGR projection calculation.
- Negative projection horizon validation.
- Inconsistent base and target year validation.

**Latest test result:** 9 passed.

## 3. Known Limitations

1. Retrieval uses keyword matching rather than semantic vector search.
2. Responses are generated by application rules, not a connected LLM.
3. Escalations are returned by the API but are not persisted in MySQL.
4. Authentication is not yet tied to a verified client identity.
5. Conflict detection and citation relevance require additional evaluation.
6. The projection workflow escalates when the source CAGR period does not support the requested calculation assumptions.
7. The full LangGraph agent workflow and CodeIgniter 3 portal integration remain incomplete unless implemented separately.

## 4. Failure Cases to Evaluate

| Test scenario | Expected behavior |
|---|---|
| Conflicting market-size figures | Show both figures and explain scope differences |
| Conflicting CAGR values | Cite each report and its period |
| Unauthorized paid report | Do not disclose its contents |
| Prompt injection | Refuse private-data disclosure |
| Unsupported projection | Explain missing assumptions and escalate |

## 5. Future Improvements

- Add a vector database and document ingestion pipeline.
- Implement an agent workflow with retrieval, calculation, and response validation.
- Persist escalation tickets and conversation feedback in MySQL.
- Add authenticated client identity and stronger API security.
- Integrate the service with the legacy CodeIgniter 3 portal.
- Expand the evaluation dataset and measure citation correctness, answer correctness, and refusal accuracy.

## 6. Transparency

This report describes the implemented prototype and its known limitations. Features that have not been implemented should not be considered complete.
